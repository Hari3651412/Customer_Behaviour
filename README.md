# Customer Behavior Analysis Dashboard

## 📊 Project Overview
This project analyzes customer shopping behavior to uncover insights about purchasing patterns, revenue distribution, and customer segmentation.

Using **SQL for data analysis** and **Power BI for visualization**, the project explores how different customer groups contribute to overall sales and how product categories perform.

---

## 📁 Dataset
The dataset contains customer shopping behavior information including:

- Customer demographics
- Product categories
- Purchase amounts
- Shipping types
- Subscription status
- Review ratings

File used:
```
customer_shopping_behavior.csv
```

---

## 🛠 Tools & Technologies
- **SQL** – Data exploration and customer segmentation  
- **Power BI** – Data visualization and dashboard creation  
- **CSV / Excel** – Dataset storage

## 📊 Dashboard Features

### Customer Subscription Analysis
- 73% **Non-Subscribers**
- 27% **Subscribers**

### Revenue by Category
The dashboard analyzes revenue contribution from major categories such as:
- Clothing
- Accessories
- Footwear
- Outerwear

### Revenue by Age Group
Customer segments analyzed by age group:
- Young Adult
- Adult
- Middle-aged
- Senior

### Sales Performance
Visualization of how different product categories contribute to overall sales.

---

## 🧠 Key Insights
- Majority of customers are **non-subscribers**, indicating potential opportunities for subscription programs.
- Certain product categories contribute significantly to total revenue.
- Customer purchasing behavior varies across different age groups.
